# Riffoid IR Plugin 阶段性实验报告网页

- `index.html`：可直接由 GitHub Pages 发布的自包含静态报告网页。
- `report.md`：Markdown 版本，可用于 GitHub 仓库预览或后续编辑。
- `README.md`：本说明。

## GitHub Pages 发布

1. 将本目录中的文件上传到 GitHub 仓库根目录。
2. 打开仓库 `Settings → Pages`。
3. 在 `Build and deployment` 中选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/(root)`，点击 `Save`。
5. 等待部署完成后，点击 `Visit site`。

建议先检查报告中是否包含不适合公开的信息。此版本只转换报告文本和表格，不会自动上传模型文件或运行证据附件。
